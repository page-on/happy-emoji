## Context

已有视频表情包制作流程（选取→裁剪→文字→导出GIF）。在此基砡上增加照片输入支持。照片输入时跳过裁剪步骤，最终输出为静态图片（PNG），而非 GIF。其他步骤（文字编辑、拖拽定位）保持不变。

## Goals / Non-Goals

**Goals:**
- 在素材选取阶段支持选择照片（jpg/png/webp）
- 照片模式下跳过视频裁剪步骤
- 照片+文字导出为 PNG 图片并保存

**Non-Goals:**
- 不支持照片与视频混合处理
- 不支持多张照片拼接
- 不支持照片裁剪/编辑（仅叠加文字）

## Decisions

### 1. 状态模型：增加 mediaType 字段

在全局 state 中增加 `mediaType: 'video' | 'photo'`，以及 `photoFile`/`photoUrl`。根据 `mediaType` 决定导航流程和导出方式。

理由：最小侵入，不破坏现有视频流程。

### 2. 素材选取 UI：双按钮入口

在第一界面提供两个选择按钮："从相册选取视频"和"从相册选取照片"，分别触发不同的文件选择器（`accept="video/*"` 和 `accept="image/*"`）。

备选：单一按钮 + 弹出选择 → 多一次点击，体验更差。

### 3. 导航跳转：根据 mediaType 决定下一步

- 视频模式：步骤 0 → 1（裁剪）→ 2（文字）→ 3（导出）
- 照片模式：步骤 0 → 2（文字）→ 3（导出），步骤 1 被跳过

步骤指示器和"下一步/上一步"按钮都需感知当前模式。

### 4. 照片预览：使用 \<img\> 标签

文字编辑界面中的预览区，照片模式使用 `<img>`，视频模式使用 `<video>`。文字 overlay div 逻辑不变。

### 5. 图片导出：Canvas 合成 + PNG 下载

使用 Canvas API：
1. 加载照片到 Image 对象
2. 在 Canvas 上绘制照片（等比缩放至 480px 宽）
3. 在 Canvas 上绘制文字
4. 通过 `canvas.toBlob('image/png')` 导出并下载

无需引入额外库，浏览器原生支持。

### 6. 进度指示器适配

步骤条在照片模式下仅显示 3 个步骤（1 选素材 → 2 加文字 → 3 导出），隐藏第 2 个步骤点。

## Risks / Trade-offs

- **[风险] 高清照片导出 PNG 较大**：480px 宽度下 PNG 约 200KB-1MB。→ 接受，PNG 无损质量优先
- **[权衡] 照片模式无裁剪功能**：用户无法裁剪照片。→ 后续迭代可增加，当前聚焦核心流程
