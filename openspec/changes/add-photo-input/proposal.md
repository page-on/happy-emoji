## Why

目前 APP 仅支持从相册选取视频制作动图表情包。用户还需要用静态照片制作带文字的图片表情包（jpg/png 表情包），这是表情包制作的另一大使用场景。增加照片输入可以让 APP 覆盖更广泛的需求。

## What Changes

- 素材选取界面增加照片选项，支持从相册选取图片（jpg/png/webp）
- 选取照片后跳过视频裁剪步骤（第二步），直接进入文字编辑
- 照片模式下输出静态图片（PNG）而非 GIF，保存到系统相册
- 文字编辑和拖动逻辑与视频模式一致，无需修改

## Capabilities

### New Capabilities

- `photo-input`: 从系统相册选取照片作为素材来源，支持常见图片格式
- `image-export`: 将照片与文字叠加后导出为静态图片（PNG），保存到系统相册

### Modified Capabilities

- `video-selection`: 素材选取界面从"仅视频"改为"视频或照片"，用户可在同一入口选择
- `gif-export`: 导出逻辑增加图片模式分支 — 照片输入时导出 PNG 静止图片，视频输入时仍导出 GIF

## Impact

- 第一界面（素材选取）：UI 增加照片/视频切换或双入口
- 导航流程：照片模式跳过第二步裁剪，流程变为 选取 → 加文字 → 导出（3步）
- 导出模块：增加 Canvas 静态图片合成 + 导出逻辑
- 无新增外部依赖，使用现有 Canvas API 即可
