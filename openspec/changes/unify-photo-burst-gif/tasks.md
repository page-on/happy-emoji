## Tasks: 图片转GIF 统一模式

### T-1 素材选取改造

- [ ] Step 0 UI：3 入口 → 2 入口（保留 🎬 视频，🖼 照片+📸 连拍 合并为 🖼 图片转GIF）

- [ ] 选完判定：`count == 1` → 跳过排序，进入文字编辑；`count >= 2` → 进入帧排序

### T-2 帧排序（条件显示）

- [ ] `count >= 2` 时显示缩略图网格 + 拖拽排序 + 删除 + 追加 + 帧间隔滑块

- [ ] 文字控件（输入/字体/颜色/字号/拖拽）复用同一组件
