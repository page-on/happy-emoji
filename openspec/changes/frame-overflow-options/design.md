## Context

当前帧数溢出仅显示红色文字，用户被动接受截断。需要给用户主动选择权。

## Decisions

### 方案 A：缩短选段
- 操作：点击按钮后高亮 trim 滑块（闪烁边框动画），引导用户拖动缩短
- 实时反馈：帧数回到 ≤ 60 时红色消失，按钮隐藏
- 无需代码改动筛选逻辑

### 方案 B：均匀采样
- 操作：点击"均匀采样"按钮 → `state.sampleMode = 'uniform'`
- 帧提取时：`step = totalFrames / 60`，取 `i * step` 位置的帧
- 覆盖整个选段时长（不丢失任何区域），只是帧率降低
- 文件大小与截断模式相同（都是 60 帧），但画面更流畅

### UI 状态

```
[正常]  预计 40 帧 / 约 350 KB          ← 不显示按钮
[溢出]  预计 60 帧（已截断，上限 60 帧）  ← 红色 + 两按钮
        [缩短选段]  [均匀采样]
[采样]  预计 60 帧（均匀采样自 80 帧）   ← 蓝色，单按钮 [取消采样]
```
